Nobody's Country Uploader — Privacy Policy

Last updated: 25 August 2026

Scope

This policy covers Nobody's Country Uploader, a private application operated by Axel Arumí Garcia. The application has exactly one user: its operator. It is not offered to the public.

Data accessed

Through the YouTube Data API and the YouTube Analytics API, the application accesses only the operator's own YouTube channel: it uploads videos and their metadata, and reads that channel's performance statistics. It does not access any other Google account, service, or user's data.

Data collected from others

None. The application has no other users, no visitors, no forms, no analytics, and no tracking. No third-party personal data is collected, processed, or stored.

Storage

OAuth credentials are stored as environment variables on a private server operated by the owner, readable only by the application's system user. They are never committed to version control, never shared, and never transmitted to any third party.

Use limitation

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained through these APIs is used solely to operate the owner's own channel, and is never sold, transferred, or used for advertising.

Retention and deletion

Analytics data is retained on the owner's server for as long as the channel operates. Access can be revoked at any time by the operator at myaccount.google.com/permissions, which immediately terminates the application's access.
